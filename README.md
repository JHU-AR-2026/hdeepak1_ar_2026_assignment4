# Introduction to Augmented Reality - Assignment 4

**Author:** Harihar Prasad

This repository contains my solutions for Assignment 4, including the written Kalman filter answers, Python implementations for Questions 1e and 1f, their output plots, and the Unity game for Question 2.

## Running Question 1

Install NumPy and Matplotlib, then run the scripts from the repository root:

```bash
python3 "Question 1/Q1e.py"
python3 "Question 1/Q1f.py"
```

Each script saves its output plot inside the `Question 1` folder.

## Running Question 2

1. Open Unity Hub and select **Add project from disk**.
2. Choose the `Question 2` folder.
3. Open `Assets/Scenes/SampleScene.unity`.
4. Press **Play**, then select **START** to enable gravity and player controls.

Use **WASD** or the **arrow keys** to move and **Space** to jump.
